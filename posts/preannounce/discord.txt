## WAM Coin — mainnet in 11 days

**15 September 2026, 00:00 UTC.** RandomX on CPU, 22,000,000 hard cap, no
presale, nothing to buy, everyone starts at the same block.

Every new chain asks you to trust it. Here is what you can check *before
this one exists*.

**The premine is locked by consensus, not by promise.**

2,000,000 WAM is minted in genesis. Not one coin can move on launch day, or
in the first year. Five outputs of 400,000, each behind a bare
`OP_CHECKLOCKTIMEVERIFY` script carrying a date:

```
2027-09-15   2028-09-15   2029-09-15   2030-09-15   2031-09-15
```

Bare, not P2SH — the unlock date sits in the output itself rather than
behind a hash you would have to take our word about. Read it yourself:

```
wam-cli getblock $(wam-cli getblockhash 0) 2
```

**The releases are signed.**

```
4BD4 A8D3 AFD4 3F5C BCB5  00E2 3798 462F E00A DBA4
```
<https://github.com/wam-coin-official/wam-coin/releases/tag/v0.1.6>

Download the release, SHA256SUMS and SHA256SUMS.asc into one directory.
The checker and the key come from the repository — deliberately a different
place from the binary:
```
git clone https://github.com/wam-coin-official/wam-coin
bash wam-coin/scripts/verify_release.sh ~/Downloads
```

It will not print ok unless the signature is good, made by that exact
fingerprint, and covering the file in front of you. Verify the fingerprint
from SECURITY.md on GitHub over HTTPS — not from this message.
