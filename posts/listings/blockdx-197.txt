Two things for the docker wallet test, so they do not cost you time.

Signed releases now exist for all three desktop platforms — Linux x86_64,
Windows x86_64 and macOS arm64 — with SHA256SUMS signed by the release key:

  https://github.com/wam-coin-official/wam-coin/releases/tag/v0.1.8

`manifest-entry.json` here now lists v0.1.6, v0.1.7 and v0.1.8. The conf
file is unchanged and still keyed to `wam--v0.1.6`: nothing in the RPC
interface, the datadir layout or the address encoding has moved across
those releases.

And the one that will look like a bug if you meet it cold: **mainnet opens
2026-09-15 00:00:00 UTC**, and a mainnet node started before that refuses
to run. The genesis block is dated in the future, so Bitcoin Core's own
startup verification accepts it once from an empty datadir and refuses on
every start afterwards. It is upstream behaviour, not something we added.
From tomorrow the question disappears.

If it is easier to test against a chain that is already live, `wamd
-testnet` reaches testnet with no configuration — it has been running since
August and the seeds are in chainparams.
