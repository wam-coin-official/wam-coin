Following up, and leading with the identifiers rather than the name, since
the name is what caused the confusion.

This is not the WAM gaming token and is not a fork of any coin Bisq
already lists. It is a Bitcoin Core v28.1 fork with its own genesis:

  mainnet genesis   d8d3debea987b62a0934c3980d62bffbb6e16aa797d19891d4fcc9b9fb11d7e9
  merkle root       230fc579dfbad4cec208c43392e3178760fcd74617e4ef22903eae7bf7fcff29
  network magic     0x57 0x41 0x4d 0x21   ("WAM!")
  P2P port          9555
  bech32 HRP        wam
  PUBKEY_ADDRESS    73   — addresses begin with W
  source            https://github.com/wam-coin-official/wam-coin
  licence           MIT

Proof of work is RandomX, so it is CPU-mined; there is no premine, no ICO,
no token sale and no smart contract. Nothing about it exists on another
chain, which is why searching the name finds something else entirely.

The `WAMCoin.java` and `WAMCoinTest.java` in this PR follow the same shape
as the other altcoin entries: address validation against the mainnet
prefixes above, with the test vectors generated from this chain.

Signed binaries for Linux, Windows and macOS:

  https://github.com/wam-coin-official/wam-coin/releases/tag/v0.1.8

Mainnet opens 2026-09-15 00:00 UTC. Testnet has been running since August
if anything is easier to check against a live chain. The complete parameter
set, including everything an address-validation review usually asks for, is
at
https://github.com/wam-coin-official/wam-coin/blob/main/docs/LISTING_PACKAGE.md
