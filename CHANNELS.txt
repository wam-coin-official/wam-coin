 A fake pool takes your hash rate; a fake Electrum server can lie to your

 There are no others. No Reddit, no Instagram, no second Telegram group,
 no second Discord, no second BitcoinTalk thread, no "support" account, no
 exchange listing, no presale, no airdrop, no token sale, no wallet app. If
 you have found one of those and it says WAM, it is not us.


 WHAT NOBODY OFFICIAL WILL EVER DO
 ---------------------------------

   * ask you for a seed phrase, private key, or wallet file
   * ask you to send coins anywhere to "verify", "unlock" or "register"
   * ask you for money, in any currency, for any reason
   * message you first
   * offer you a guaranteed return, an allocation, or an early price

 Every one of those is the whole of crypto fraud. There is no sixth kind.
 The correct response to all five is to stop reading.


 HOW TO CHECK THIS FILE
 ----------------------

 Accounts that link to each other prove very little: whoever takes one of
 them can point it at a row of impostors. So this file is meant to be
 signed.

   curl -O https://wamcoin.org/CHANNELS.txt
   curl -O https://wamcoin.org/CHANNELS.txt.asc
   gpg --verify CHANNELS.txt.asc CHANNELS.txt

 The fingerprint that must come back is published in SECURITY.md in the
 source repository, and nowhere else. Compare it character by character.
 A signature that verifies against some other key proves nothing at all.

 The key that signs this is kept offline and is not on any machine that
 faces the internet. The same key signs every release from v0.1.6, so the
 signature on your download and the signature on this list are the same
 claim, made once and checkable twice.

 A signature covers exact bytes. This file is revised whenever a channel is
 added, and every revision needs a new signature -- so if the verification
 fails, the likely reason is that you hold the signature of a different
 revision. Fetch both again from the same place, together.

 Revisions 1 and 2 were never signed at all, and said so, but gave a reason
 that had stopped being true: that the key ceremony had not been held. It
 had. The file simply had not been signed with it, and nobody noticed the
 sentence had gone stale for a fortnight.


 WHAT THIS FILE DOES NOT CLAIM
 -----------------------------

 That the software is safe. No third-party security audit has been done.
 That the coin is worth anything. It has no price and may never have one.
 That the project will continue. Most do not.

 This file establishes who is speaking. Nothing more.
